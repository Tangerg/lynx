## Scope

## Boundaries

Each provider and shared wire protocol remains an independently versioned leaf. The family owns translation boundaries, not shared model semantics, orchestration, or product policy.

Individual adapters document their own conceptual boundary. Their public APIs and executable usage live in GoDoc and checked examples.
