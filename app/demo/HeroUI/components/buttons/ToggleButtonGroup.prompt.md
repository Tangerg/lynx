A tray of ToggleButtons that reads as one segmented switch — the selected item lifts onto `--segment` with the surface shadow.

```jsx
<ToggleButtonGroup>
  <ToggleButton size="sm" isSelected>Grid</ToggleButton>
  <ToggleButton size="sm">List</ToggleButton>
</ToggleButtonGroup>
```

Use `size="sm"` inside the tray so the group stays 40px tall.
