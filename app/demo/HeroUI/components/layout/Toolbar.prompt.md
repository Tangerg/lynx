A floating tray for icon actions — surface fill, fully rounded, 4px padding.

```jsx
<Toolbar>
  <Button variant="ghost" size="sm" isIconOnly aria-label="Bold"><Icon name="code" /></Button>
  <Toolbar.Separator />
  <Button variant="ghost" size="sm" isIconOnly aria-label="Delete"><Icon name="trash" /></Button>
</Toolbar>
```
