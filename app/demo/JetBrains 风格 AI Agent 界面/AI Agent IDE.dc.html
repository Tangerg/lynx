抽出的 hook
核心是把幂等键固定在 useRef 上，整个重试周期共用一个 key —— 否则每次重试都会被网关当成新订单。
  • 指数退避：400ms → 800ms → 1600ms，封顶 3 次
  • 可取消：组件卸载时 abort，不再写状态
  • 可观测：每次失败上报 payment.retry 事件
注意：PaymentError 里 code === 'card_declined' 属于终态，不该重试。详见 支付错误码约定。
